# ExpenseFlow — Interactive Expense Tracker

A responsive browser-based Interactive Expense Tracker developed as part of the Veda Technology Web Development Internship — Task 42.

## 📌 Project Overview

ExpenseFlow is a client-side expense management web application that allows users to record, organize, search, filter, sort, edit, and delete personal expense records.

The application uses JavaScript and browser LocalStorage to maintain expense data without requiring a backend or database.

## 🎯 Objective

The objective of Task 42 is to strengthen practical JavaScript development skills through:

- DOM manipulation
- Event handling
- Arrays and objects
- CRUD operations
- LocalStorage
- Form handling
- Validation
- Filtering
- Sorting
- Dynamic UI updates
- Responsive web design

## ✨ Key Features

### Expense Management

- Add new expenses
- Edit existing expenses
- Delete individual expenses
- Clear all expense records
- Expense title, amount, category and date

### Search & Filtering

- Search by expense title
- Search by category
- Filter by category
- Filter by today
- Filter by last 7 days
- Filter by current month

### Sorting

- Newest first
- Oldest first
- Amount: High to Low
- Amount: Low to High
- Title: A to Z

### Dashboard

- Total spending
- Total number of expenses
- Visible expense count
- Categories used
- Category-wise spending summary
- Dynamic spending bars

### Data Persistence

Expense records are stored in the browser using LocalStorage.

The application does not require:

- Backend server
- Database
- Login system
- External API
